# 契约：界面状态与交互

**版本**: v1 | **日期**: 2026-09-29 | **关联**: [data-model.md](../data-model.md) §6/§7 · spec FR-024~FR-029

## 视图结构（单视图切换，FR-025）

```text
┌─ 视图 A：网站列表（主页） ─────────────┐
│ 添加 URL 输入框                        │
│ 网站条目网格（图标+名称，悬停子菜单）   │
└───────────────────────────────────────┘
              ↕ 打开网站 / 返回主页
┌─ 视图 B：网页浏览 ─────────────────────┐
│ 紧凑标签栏（图标+截断标题+标签列表钮）  │
│ 导航条（主页/前进/后退/刷新/地址/菜单） │
│ iframe 内容区（占满剩余空间）           │
│ 降级覆盖层（blocked/failed 时显示）     │
└───────────────────────────────────────┘
```

- 无打开标签页时总是视图 A；视图 B 中网站列表不常驻（FR-025）。

## 紧凑标签栏（FR-024）

- 每项：favicon + 标题（约 12 字符截断）+ 活动态高亮；关闭按钮在悬停/聚焦时显现。
- 空间不足：可见项保持活动标签可见，其余进入「标签列表」下拉（含全部标签的完整标题与关闭操作）。
- 20 个标签页内不引入虚拟滚动（SC-003 上限即 20）。

## 悬停图标子菜单（FR-026~FR-028）

| 上下文 | 菜单项 |
|--------|--------|
| 标签页项 | 刷新、复制网址、在普通标签页打开、关闭 |
| 导航区 | 前进、后退、刷新、复制当前网址 |
| 网站条目 | 打开、编辑名称、删除、切换移动/桌面、授权设置 |
| 站点设置钮 | 移动/桌面切换、真实移动 UA 开关、登录复用开关、能力状态说明 |

交互规则：

- 打开：鼠标悬停（延迟 ~150ms 防抖）/ 触摸点击 / 键盘聚焦后 Enter 或 Space。
- 关闭：Esc / 点击菜单外 / 触发某操作后。
- ARIA：触发钮 `aria-haspopup="menu"` `aria-expanded`；菜单 `role="menu"`，项 `role="menuitem"`；仅图标按钮必须有 `aria-label` 与可见焦点环。
- 菜单打开不劫持页面滚动；触摸环境一次只能打开一个菜单。
- **接线生命周期**：重绘会重建锚点元素，其接线必须随之释放（`iconMenu.pruneDetached`）。不释放则表按重绘轮数无界增长，且失效接线仍持有监听器。

## 站点设置面板的来源绑定（FR-038，终审 D2）

面板显示的每一项都属于**一个精确来源**。规则：

- 面板记录其所属 `originKey`；任何异步回调（能力状态刷新、授权返回）在重绘前必须比对，**不属于该来源则不得重绘**。
- 面板关闭时清除该记录（含登记的重绘器）。
- 理由：授权对话框返回、能力查询返回都是异步的，期间用户完全可以切到别的站点并打开新面板。少了这层绑定，旧来源的回调会把新面板的内容改写成旧来源的状态 —— 界面显示的授权与徽章与它标着的那一行不对应，用户据此点开关会改错站点。

## 能力状态徽章（FR-029）

| 状态 | 文案（示例） | 颜色语义 |
|------|--------------|----------|
| unauthorized | 「未授权」 | 中性灰 |
| active / available | 「真实移动 UA」/「已检测到会话」 | 正常色 |
| absent（仅 Cookie） | 「未检测到会话」 | 中性灰 |
| degraded | 「已降级为移动视口」 | 警示色 |
| limited（仅 Cookie） | 「能力受限」 | 警示色 |
| unsupported（仅 UA） | 「当前浏览器不支持」 | 警示色 |
| failed | 「加载失败」 | 错误色 |
| uncertain / unknown | 「地址可能未同步」/「未知」 | 中性灰 |

- 禁止出现「视口模式显示为真实 UA」之类误导（spec SC-005）。
- **`available` 与 `absent` 必须分开（终审 B2）**：两者都是"能力可用"（API 正常、权限在手），
  区别只在**存在性探测的结论**。「已检测到会话」声称的事实是"这个站点有会话"，
  没有会话却这么说，用户会据此以为登录态可用。`absent` 用中性灰而非警示色 ——
  没有会话是常见情况，不是故障。
- `limited` 与 `unauthorized` 同样不得混用：前者是"授权了但 API 不可用"，后者是"没授权"，用户要做的事不同（换浏览器 vs 去授权）。

## 降级覆盖层（FR-006）

触发：loadState = `blocked` 或 `failed`。

内容：状态说明（用户可懂的一句话）+「重试」+「在当前标签页打开」+「在新标签页打开」+「返回主页」。

- 覆盖层不渲染目标网站返回的任何 HTML（FR-034）。
- 失败的 URL 保留在历史中，但不覆盖此前成功条目的标题。

## 空态与错误态

| 场景 | 表现 |
|------|------|
| 无网站条目 | 添加输入框 + 引导文案 |
| 无标签页 | 回到视图 A |
| 存储失败 | 顶部警示条「会话可能无法完整恢复」 |
| 权限被拒 | 对应开关回弹为关 + 「未授权，已使用降级模式」提示 |
